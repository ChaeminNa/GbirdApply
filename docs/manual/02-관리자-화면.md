# 관리자 화면

## 로그인

- 랜딩 화면에서 "관리자" 진입 → **관리자 비밀번호**와 (최초 1회) **관리자 토큰** 입력
- 관리자 비밀번호와 관리자 토큰은 서로 다른 값입니다. 둘 다 필요한 이유는 [`../HANDOVER.md`](../HANDOVER.md#운영-원칙--알아둘-특이사항-요약) 참고.
- 한 번 로그인하면 브라우저에 저장되어, **새로고침해도 다시 로그인할 필요가 없고 보고 있던 화면(설정/목록 탭)으로 그대로 돌아옵니다.**
- 공용 컴퓨터에서는 관리자 화면 우측 상단의 **로그아웃**을 눌러 로그인 상태를 지워주세요.

## 화면 구성

관리자 화면은 "구글 시트 연동"(설정) 탭과 "정보 수동 입력"(목록) 탭 두 개로 나뉩니다. 상단에는 항상 현재 지원자 수와 **"구글 시트에서 열기 ↗"** 링크가 있어, 클릭 한 번으로 실제 스프레드시트를 새 탭에서 열 수 있습니다.

### 구글 시트 연동 탭

버튼들이 실제로 쓰는 시점 순서대로 ①~⑤ 단계로 라벨링되어 있습니다.

| 단계 | 용도 | 빈도 |
|---|---|---|
| ① Apps Script 배포 | 코드 복사 → Apps Script 편집기에 붙여넣고 배포 | 시즌 처음 열 때 한 번 |
| ② 배포 주소 연결 | 배포로 나온 `.../exec` 주소 입력·저장 | 시즌 처음 열 때 한 번 (재배포로 주소가 바뀌면 다시) |
| ③ 운영 중 자주 사용 | "시트에서 불러오기" — 최신 지원자 목록 갱신 | 모집 기간 내내 자주 |
| ④ 면접 일정 입력 | 면접 날짜·장소·마감·시각공개·결과공개 일시 | 시즌마다 한 번(바뀌면 다시) |
| ⑤ 시즌 공개 | "이 시즌을 지원자에게 공개하기" | 시즌 준비가 끝난 마지막 단계 |

자세한 배포 절차는 [`../setup/01-Apps-Script-배포.md`](../setup/01-Apps-Script-배포.md) 참고.

### 정보 수동 입력 탭

- 지원자별로 **면접 시각**(`HH:MM`)과 **합격 여부**를 입력합니다. 저장 버튼 없이, 입력 칸에서 손을 떼면 바로 시트에 저장됩니다.
- 면접 시각은 설정한 "면접 시각 공개 일시" 이후, 합격 여부는 "합격 발표 일시" 이후부터 지원자에게 보입니다. 그 전에 미리 채워도 지원자에게는 노출되지 않습니다.
- "공개 전 미리보기"로 지원자가 볼 면접 안내 화면을 미리 확인할 수 있습니다.
- 목록의 ✕(지우기)는 **이 화면에서만** 지원자를 안 보이게 할 뿐, 시트의 행은 지우지 않습니다. 시트에서 완전히 없애려면 시트에서 직접 행을 삭제해야 합니다 — [`../HANDOVER.md`](../HANDOVER.md)의 관련 항목 참고.

## 시즌 전환

상단의 "보는 중인 시즌"에서 연도 + 봄/가을을 골라 "이 시즌 보기"를 누르면, 그 시즌의 지원자 목록을 불러와 확인할 수 있습니다. 실제로 지원자에게 공개되는 시즌은 "이 시즌을 지원자에게 공개하기"를 눌러야 바뀝니다 — 단순히 "보는 중인 시즌"을 바꾸는 것만으로는 지원자 화면에 영향이 없습니다.
