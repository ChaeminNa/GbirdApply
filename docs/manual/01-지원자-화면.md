# 지원자 화면

지원자가 지원 링크를 열었을 때 겪는 화면 흐름입니다.

## 흐름

1. **랜딩 화면** → "지원하기" 또는 "지원 확인/수정" 중 선택
2. **로그인 게이트**: 이름 + 전화번호로 본인 확인
   - 지원하기: 신규 지원서 작성 화면으로 이동
   - 확인/수정: 전화번호로 기존 지원서를 조회해 불러옴
3. **지원서 작성/수정**: 성함, 성별, 전화번호, 이메일, 생년월일, 학과/학위/재학학기, 배드민턴 경험, 참여 가능 시간, 취미, 유입 경로, 하고 싶은 말
   - 전화번호는 `010-1234-5678` 형식이 아니면 제출이 막힙니다.
   - 같은 전화번호로 이미 접수된 지원서가 있으면 중복 제출을 막고 기존 지원서로 안내합니다.
4. **내 지원 현황(`me`) 화면**: 제출 완료 확인, 면접 시각 확인, **참석 여부(RSVP) 응답**, 불참/변경 사유 입력, (합격 발표 시점 이후) 합격 여부 확인

## 노출 시점 제어

마감/면접시각 공개/결과 공개는 운영진이 [관리자 화면](02-관리자-화면.md)에서 설정한 날짜·시각(`close`, `reveal`, `result`) 기준으로 자동으로 열리고 닫힙니다. 코드를 고칠 필요 없이 관리자 화면에서 날짜만 바꾸면 됩니다.

## 참고

- 지원서 제출/수정/RSVP 요청이 네트워크 문제 등으로 실패해도 입력한 내용이 조용히 사라지지 않도록 되어 있습니다 — 실패 시 사용자에게 안내 메시지가 뜹니다.
- 카카오톡 등 인앱 브라우저에서 지원 조회가 깨졌던 이력이 있으니, 이 화면을 고칠 때는 인앱 브라우저에서도 실제로 테스트해주세요.
