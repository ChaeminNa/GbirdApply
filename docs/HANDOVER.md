# G-Bird 지원서 인수인계

이 저장소는 G-Bird 동아리 신입 부원 모집 지원서 웹앱을 보관하는 인수인계용 저장소입니다.

## 구성

- `index.html`: 지원자·관리자 화면 전부(프런트엔드) + Apps Script 백엔드 코드 원본을 함께 담고 있는 파일 하나. 직접 손으로 고치는 파일이 아닙니다 — 이유와 방법은 [`setup/02-index-html-직접-수정.md`](setup/02-index-html-직접-수정.md).
- `docs/manual/`: 화면별 사용 매뉴얼
- `docs/setup/`: 배포·설정 절차
- `docs/integrations/`: Google 스프레드시트 연동 구조(API 액션, 시트 컬럼)

백엔드 코드(Apps Script)는 별도 저장소나 파일로 관리되지 않고, `index.html` 안에 문자열로 내장되어 있습니다. 관리자 화면의 "Apps Script 코드 복사" 버튼으로 언제든 꺼낼 수 있습니다.

## 새 담당자가 처음 받을 것

1. 이 Git 저장소 접근 권한 (GitHub: `ChaeminNa/GbirdApply`)
2. 지원서 데이터가 담긴 Google 스프레드시트 접근 권한
3. 관리자 비밀번호 (지원 페이지 로그인용)
4. 관리자 토큰(`ADMIN_TOKEN`) — Apps Script 스크립트 속성에 저장된 값. 백엔드 API 호출 인가용으로 비밀번호와는 별개입니다.
5. 배포 플랫폼(GitHub Pages 등) 접근 권한

비밀번호와 토큰은 Git에 커밋하지 않습니다.

## 운영 원칙 · 알아둘 특이사항 요약

- **시트가 source of truth입니다.** 관리자 화면에 로컬로 캐시된 지원자 목록과 실제 시트 내용이 다르면, 로그인 시 항상 시트 기준으로 재동기화합니다.
- **관리자 비밀번호 ≠ 관리자 토큰.** 비밀번호는 관리자 화면 진입을 막는 프런트엔드 로컬 게이트(해시만 코드에 존재)이고, 토큰(`ADMIN_TOKEN`)은 Apps Script 쪽 실제 쓰기/조회 API를 인가하는 값입니다. 인수인계 시 두 값을 모두 전달해야 합니다.
- **시트 행을 앱에서 지워도 시트에는 남습니다.** 관리자 화면의 "명단에서 지우기"는 그 화면에서만 안 보이게 할 뿐 시트 행을 지우지 않습니다. 시트에서 지원자를 완전히 없애려면 시트에서 직접 **행 번호를 우클릭 → 행 삭제**를 해야 합니다(Delete 키로 셀 내용만 지우면 빈 행이 남습니다).
- **Apps Script 웹앱 URL은 재배포할 때마다 바뀔 수 있습니다.** 재배포했다면 관리자 화면의 "Apps Script 웹 앱 주소"에 새 `.../exec` 주소를 다시 입력해야 합니다.
- **관리자 로그인은 새로고침해도 유지됩니다.** 로그인 상태와 마지막으로 보던 화면(설정/목록 탭)은 브라우저에 저장되어, 새로고침해도 홈으로 나가지 않고 그대로 이어집니다. 다른 사람과 같이 쓰는 컴퓨터라면 관리자 화면의 "로그아웃"을 눌러 정리해주세요.
- **카카오톡 등 인앱 브라우저에서 깨진 적이 있습니다.** 새 기능을 추가하면 일반 브라우저뿐 아니라 카카오톡/인스타그램 인앱 브라우저에서도 지원/조회/RSVP 플로우를 실제로 테스트하는 게 안전합니다.

자세한 절차는 각 문서를 참고하세요. 이 문서는 인수인계 받을 때 전체 그림을 잡기 위한 요약본입니다.
