## 관리자 화면

- [ ] 시트에서 지원자를 완전히 제외하고 싶을 때, 지금은 시트에서 직접 행을 삭제해야 함(앱에는 "완전 삭제" 기능이 없고 "명단에서 지우기"는 로컬에서만 지움). 실수로 Delete 키로 셀만 지워서 빈 행이 남는 사고가 실제로 있었음 — 앱에 "시트 행까지 삭제" 기능을 추가하면 이런 실수를 줄일 수 있음.
- [ ] 지원 조건에 안 맞는 지원자에게 안내 문자를 보낼 때 참고할 문구가 따로 문서화되어 있지 않음. 반복될 수 있는 상황이면 매뉴얼에 문구 템플릿을 남겨두는 것도 고려.
