# Apps Script 배포

백엔드 전체가 하나의 Apps Script 파일로 되어 있고, 그 코드 원본은 `index.html` 안에 내장되어 있습니다. 코드 자체를 고쳐야 한다면 [`02-index-html-직접-수정.md`](02-index-html-직접-수정.md)를 먼저 읽어주세요. 이미 있는 코드를 그대로 새 스프레드시트에 배포하기만 한다면 아래 절차만 따르면 됩니다.

## 처음 배포하기 (시즌 처음 열 때 / 새 스프레드시트로 옮길 때)

1. 관리자 화면 → "구글 시트 연동" 탭 → **"Apps Script 코드 복사"**로 백엔드 코드 전체를 복사
2. 새 Google 스프레드시트 생성 → 확장 프로그램 > Apps Script
3. 기존 내용을 지우고 복사한 코드 전체를 붙여넣기 → 저장
4. 배포 > 새 배포 > 유형 **웹 앱** / 실행 **나** / 액세스 **모든 사용자** > 배포
5. 나온 `.../exec` 주소를 관리자 화면의 "Apps Script 웹 앱 주소"에 입력하고 저장
6. Apps Script 편집기 > 프로젝트 설정(톱니바퀴) > 스크립트 속성에서 `ADMIN_TOKEN` 값을 32자 이상의 임의 문자열로 추가 → 같은 값을 관리자 화면의 "관리자 토큰" 입력칸에도 입력

## 재배포 (코드를 고친 뒤 / URL이 필요할 때)

- Apps Script는 코드를 수정해도 **새로 배포**하지 않으면 실제 서비스에 반영되지 않습니다. 배포 > 배포 관리 > 편집(연필 아이콘) > 버전: 새 버전 > 배포.
- 재배포하면 `.../exec` 주소가 그대로 유지되는 경우도 있지만, 새 배포로 만들면 주소가 바뀔 수 있습니다. 주소가 바뀌었다면 관리자 화면의 "Apps Script 웹 앱 주소"에 새 값을 다시 입력해야 지원자 제출이 시트에 반영됩니다.

## 새 시즌 열기

코드 수정 없이 가능합니다.

1. 관리자 화면 설정 탭에서 연도 + 봄/가을 선택 (시즌 키는 `{연도}{spring|fall}` 형식, 예: `2026fall`)
2. 같은 스프레드시트 파일 안에 그 이름의 시트 탭이 **자동으로 생성**됩니다.
3. 면접 일정(면접일/마감/시각공개/결과공개)을 입력하고 "이 시즌을 지원자에게 공개하기"를 누르면 그 시즌이 지원자에게 보이는 기본 시즌이 됩니다.

자세한 관리자 화면 사용법은 [`../manual/02-관리자-화면.md`](../manual/02-관리자-화면.md) 참고.

## 관리자 비밀번호 vs 관리자 토큰

두 값은 서로 다른 메커니즘입니다. 인수인계 시 반드시 둘 다 전달하세요.

- **관리자 비밀번호**: 관리자 화면 진입을 막는 프런트엔드 로컬 게이트입니다. 코드에는 되돌릴 수 없는 해시값만 있고 평문 비밀번호는 어디에도 저장돼 있지 않습니다. 비밀번호를 바꾸려면 `index.html`을 고쳐야 하므로 [`02-index-html-직접-수정.md`](02-index-html-직접-수정.md)를 참고하세요.
- **관리자 토큰(`ADMIN_TOKEN`)**: Apps Script 스크립트 속성에 저장되는 값으로, 실제 쓰기/조회 API 호출을 인가합니다. 스크립트 속성에서 언제든 바꿀 수 있고, 바꾸면 관리자 화면에도 새 값을 다시 입력해야 합니다.
